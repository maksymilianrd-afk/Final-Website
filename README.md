## Connecting this repo to Shopify

To have changes pushed here show up in Shopify automatically, use Shopify's
GitHub integration:

1. In Shopify admin, go to **Online Store → Themes**
2. Click **Add theme → Connect from GitHub**
3. Select this repository (`maksymilianrd-afk/Final-Website`) and a branch

Once connected, every push to the linked branch is synced to the theme in
Shopify automatically.
